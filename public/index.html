    How saving and offline work
    
      
    Your files are saved in this browser, on this device, using IndexedDB. Nothing is sent to a server, and closing the tab or losing Wi-Fi does not delete anything.
    
      
      
        
    • They stay until you clear this site's data, use a private or incognito window, or remove the browser.
      • 
        
    • Another browser or another device has its own, separate files. Use Back up all files (More menu) to move them.

      Tips and limits
      
      
        
        
      • Run: Ctrl+Enter (Cmd+Enter on Mac). Save now: Ctrl+S. Saving also happens automatically.
        • 
        
      • Input: programs that ask questions (input() or cin) read their answers from the Input tab, one per line.
        • 
        
      • Python 3.12 runs with Pyodide 0.26.4: the standard library works (math, random, datetime...). Extra packages and turtle or tkinter do not.
        • 
        
      • C++ runs with JSCPP 2.0.9, a small interpreter for beginner C++ (it is not a full compiler and has no C++ version number; it follows the basics of old-style C++98). It handles variables, loops, functions, arrays, pointers and cin/cout. std::string, references (&), struct, classes, vectors, new/delete, templates, exceptions and file handling do not run here; use a real compiler such as g++ for those. The cheat sheet tags each topic.
        • 
        
      • Stuck in a loop? Press Stop. Programs also stop by themselves after 15 seconds.
